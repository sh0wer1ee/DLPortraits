# DLPortraits

Dragalia Lost portrait viewer (rebuilt)

Rewriting in plain HTML + ES modules，faster loading and friendlier UI.

Faces are no longer stitched together from arbitrary parts — the viewer only offers the
expression groups the game actually defines, so the alpha glitches on the part edges are gone now.

Feel free and welcome to contribute to this repo.
